# Lab 03 CSS Practices

This repository contains the completion of Lab 03 tasks for CS 224L Web Technologies.

## Structure
- `index.html`: Main portfolio and showcase for Tasks 5-10
- `exercises/`: Contains specific task pages for Selectors, Typography, Backgrounds, and Images
- `styles/`: Modularized CSS (main, typography, components, effects)
- `images/`: Organized images
